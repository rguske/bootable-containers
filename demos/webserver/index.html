What is this?

This web server runs on a bootable container — an immutable, container-based operating system. The entire OS is defined in a Containerfile, built with podman, and can boot on bare metal, VMs, or cloud infrastructure.

Key Features

  • Immutable — Root filesystem is read-only
  • Atomic Updates — OS updates as a single unit
  • Rollback — Instantly revert to previous version
  • Portable — Deploy anywhere: bare metal, KVM, VMware, cloud
